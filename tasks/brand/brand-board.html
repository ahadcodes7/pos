Implementation map

Tokens: --primary is neutral; --commit is coral; --brand is coral for the mark and dot; --accent is butter for selection; --destructive-solid is the deep-red fill; --destructive is readable error text; --ring is slate.
Label rule: coral always takes an ink label (6.8:1). Cream/white on coral is 2.3–2.5:1 and fails. In light mode, coral gets a deeper inset border so the button edge clears 3:1 on paper.
